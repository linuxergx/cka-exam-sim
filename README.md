# CKA 模拟考场 UI

程少亭自用的 **CKA 真实风格模拟页**：左侧题目（点击 `<code>` 复制）+ 120 分钟倒计时 + 右侧可选网页终端。

> 本仓库只提供 **题目 UI**。考试集群、虚拟机、SSH 跳板需要你自己准备。  
> 浏览器 **不能** 直接填写 SSH 地址连进节点。

在线也可随个人站点部署：若已发布到博客，导航里会有「CKA 模拟」入口。

---

## 快速开始（只看题）

1. 克隆本仓库  
2. 用浏览器直接打开 `index.html`  
   或：

```bash
cd cka-exam-sim
python -m http.server 5500
# 浏览器打开 http://127.0.0.1:5500/
```

左侧可切换约 16 道模拟题，不接终端也能刷题面。

## 接上终端做实验（重要）

### 会不会「写好地址就连上」？

点「连接」后，页面只会把右侧 **iframe** 指到你填的 **http(s) URL**。

| 情况 | 结果 |
|------|------|
| URL 是可达的 **ttyd** 网页终端 | 右侧出现黑窗，可以敲命令 |
| 填了 `user@host` / `ssh://...` / 仅 IP 无服务 | **连不上**（本页不支持 SSH） |
| ttyd 在你内网，别人在公网打开本页 | 别人右侧空白——访问不到你的机器，这是正常的 |

所以：**地址写对 + 服务已启动 + 网络可达**，才会真的连上；不是填任意 SSH 就会进考试环境。

### 推荐：ttyd

在能操作集群的机器上：

```bash
# 安装 ttyd 后：
ttyd -p 8001 --client-option rendererType=dom -W bash
```

模拟页顶部「网页终端」填写：

```text
http://127.0.0.1:8001/
```

或局域网 IP：`http://192.168.x.x:8001/`，再点 **连接**。

进入 ttyd 之后，再按题目要求执行例如 `ssh cka000000` 等命令（这些 SSH 是在 **终端里** 发起的，不是浏览器直接 SSH）。

不需要终端时点 **断开**。

## 给「没有同一套考试环境」的人

- 可以正常使用左侧题库练习。  
- 动手环境请自备（Killer、官方模拟、自建 kubeadm 等），再按上文挂 ttyd。  
- 不要把内网考试机地址写死进公开页面指望别人连上——他们连不上你的环境。
